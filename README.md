# Full Stack Open - CI/CD & Pipeline Module

This repository contains my solutions and implementations for the CI/CD and pipeline exercises of the Full Stack Open course.

## What I Learned & Implemented

- **Automated Pipelines:** Built robust GitHub Actions workflows for building, testing (Unit & E2E using Playwright), and automated deployment.
- **Branch Protection:** Configured GitHub Rulesets and status checks (`build_and_test`) to enforce pull request reviews and block direct pushes to the `main` branch.
- **Notifications:** Integrated Discord webhook notifications for build success and failure alerts.
- **Versioning:** Automated semantic versioning and tagging using GitHub Actions.

## Commands

Start by running `npm install` inside the project folder

`npm start` to run the webpack dev server
`npm test` to run tests
`npm run eslint` to run eslint
`npm run build` to make a production build
`npm run start-prod` to run your production build
